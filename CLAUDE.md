# CLAUDE.md — Mafluencer Platform ## Projet Mafluencer est une web app de challenges créatifs pour creators/influenceurs au Maroc. Les creators relèvent des défis hebdomadaires, construisent un score public (Mafluencer Score), et les brands les contactent pour des missions payantes basées sur leur performance réelle. ## Stack Technique - Framework: Next.js 14+ (App Router) + TypeScript - Styling: Tailwind CSS 3.4+ + composants custom glassmorphism - Database: PostgreSQL via Supabase + Prisma ORM - Auth: NextAuth.js avec providers Google, Email magic link - Cache: Upstash Redis - Storage: Cloudflare R2 (vidéos et images) - Email: Resend + React Email templates - State: Zustand + TanStack React Query - Deploy: Hostinger (Node.js Apps ou VPS) ## Design System — OBLIGATOIRE Palette principale (TOUJOURS utiliser ces couleurs) : - Primary: #6366F1 (Soft Indigo) — boutons, liens, accents - Secondary: #EC4899 (Electric Pink) — gradients, highlights - Background Dark: #0F172A (Deep Slate) - Surface: #1E293B (Slate 800) avec glass effect - Glass borders: rgba(255,255,255,0.1) — white/10 - Text: #E2E8F0 (Slate 200) - Muted text: #64748B (Slate 500) - Success: #10B981 (Emerald) - Warning: #F59E0B (Amber) - Error: #EF4444 (Red) Style visuel : - DARK MODE uniquement (pas de light mode) - Glass morphism : backdrop-filter: blur(12px), bg opacity 0.05-0.1 - Border radius : 16px pour les cartes, 12px pour les boutons, 9999px pour les pills - Gradients : from-indigo-500 to-pink-500 pour les éléments importants - Shadows : shadow-lg avec couleur teintée (shadow-indigo-500/10) - Animations : transition-all duration-300, hover:scale-[1.02] - Fonts : Utilise @fontsource/outfit pour les titres, Inter pour le body - MOBILE FIRST : tous les designs commencent par mobile ## Architecture des Pages ### Pages Publiques - / (Landing page marketing avec hero, features, social proof, CTA) - /explorer (Browse les creators, leaderboard public, filtres) - /creator/[username] (Profil public d'un creator) - /auth/signin (Login/Register) - /auth/register (Inscription avec choix rôle: Creator ou Brand) - /pricing (Plans et tarifs) ### Dashboard Creator (/dashboard/creator/*) - /dashboard/creator (Overview: score, défis en cours, earnings) - /dashboard/creator/challenges (Défis disponibles cette semaine + historique) - /dashboard/creator/challenge/[id] (Détail d'un défi + soumission vidéo) - /dashboard/creator/profile (Éditer son profil, bio, niches, prix) - /dashboard/creator/earnings (Solde, historique, retrait) - /dashboard/creator/missions (Missions payantes reçues des brands) - /dashboard/creator/stats (Performance, engagement, growth) ### Dashboard Brand (/dashboard/brand/*) - /dashboard/brand (Overview: campagnes, spend, top creators) - /dashboard/brand/discover (Explorer le leaderboard, filtres, profils) - /dashboard/brand/missions/new (Créer une mission payante) - /dashboard/brand/missions (Gérer les missions en cours) - /dashboard/brand/challenges/new (Créer un défi sponsorisé) - /dashboard/brand/billing (Recharger solde, factures) ### Dashboard Admin (/dashboard/admin/*) - /dashboard/admin (Stats globales, KPIs) - /dashboard/admin/users (Gérer creators + brands) - /dashboard/admin/challenges (Créer/gérer les défis hebdomadaires) - /dashboard/admin/missions (Voir toutes les missions, commissions) - /dashboard/admin/payments (Gérer les paiements, retraits) - /dashboard/admin/reports (Analytics, revenue, growth) ## Base de Données (Prisma Schema) Modèles requis : - User (id, email, name, role: CREATOR|BRAND|ADMIN, avatar, createdAt) - CreatorProfile (userId, bio, city, niches[], score, level, tiktokHandle, instagramHandle, followersCount, engagementRate, pricePerPost, pricePerStory, pricePerVideo, portfolio[], rating) - BrandProfile (userId, companyName, industry, website, logo, balance) - Challenge (id, title, description, type: FREE|SPONSORED, brandId?, category, startDate, endDate, prizeAmount?, rules, status: DRAFT|ACTIVE|VOTING|COMPLETED) - Submission (id, challengeId, creatorId, videoUrl, thumbnailUrl, caption, views, likes, shares, comments, score, rank, status: PENDING|APPROVED|REJECTED) - Mission (id, brandId, creatorId, title, brief, budget, type: POST|STORY|VIDEO|UGC, status: PENDING|ACCEPTED|DELIVERED|PAID, contentUrl, deliveryDate) - Transaction (id, type: DEPOSIT|PAYOUT|COMMISSION|BOOST, fromUserId, toUserId, amount, currency: MAD, status: PENDING|COMPLETED|FAILED, paymentMethod) - Vote (id, submissionId, voterId, value) - Notification (id, userId, type, title, message, read, link) ## Fonctionnement du Score Mafluencer (0-1000) - Participation régulière : +50 pts par défi relevé - Qualité du contenu : votes communautaires (max +100 pts/défi) - Engagement réel : basé sur les métriques du post (max +80 pts/défi) - Fiabilité : missions livrées à temps (+30 pts/mission) - Déclin : -20 pts si skip une semaine (pour encourager la régularité) - Level basé sur le score : Rookie (0-200), Rising (200-400), Star (400-600), Elite (600-800), Legend (800-1000) ## API Routes à créer - /api/auth/* (NextAuth) - /api/creators (GET: search, filter, leaderboard) - /api/creators/[id] (GET: profil complet) - /api/challenges (GET: liste, POST: créer admin/brand) - /api/challenges/[id]/submit (POST: soumettre une vidéo) - /api/challenges/[id]/vote (POST: voter pour une soumission) - /api/missions (CRUD pour les brands) - /api/missions/[id]/accept (POST: creator accepte) - /api/missions/[id]/deliver (POST: creator livre) - /api/payments/deposit (POST: brand recharge) - /api/payments/withdraw (POST: creator retire) - /api/upload (POST: upload vidéo vers R2) - /api/notifications (GET: notifications user) - /api/admin/* (routes admin protégées) ## Règles Importantes - TOUT en français dans l'interface (mais code en anglais) - Mobile-first responsive design - Loading states avec skeletons partout - Error handling avec toast notifications - Chaque page a un titre SEO et meta description - Images optimisées avec next/image - API routes protégées par middleware auth - Rate limiting sur les routes sensibles - Validation Zod sur tous les inputs
